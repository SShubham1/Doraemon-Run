# 🚁 Doraemon Run (Archived)

> **⚠️ Historical Project (Class 9)**
> I built this game in **2019, when I was in Class 9 (Age 14)**.
> This repository is an archive of my early attempts to understand Game Dev, Game Loops, Rendering, and Physics logic.

### 🎮 Why This Exists
![Gameplay Demo](https://github.com/user-attachments/assets/1737b668-8c6c-4194-a3d7-43068a5849b0)

While my classmates were memorizing Newton's equations ($v = u + at$), I wanted to **see them in action**.
I built this from scratch using **Python & Pygame** to simulate:
* **Gravity:** Custom falling logic (acceleration).
* **Collision:** Pixel-perfect interaction between sprites.
* **State Machines:** Handling menu, game, and game-over states manually.

### 🛠️ Tech Stack
* **Language:** Python 3.x
* **Library:** Pygame (Recommended: Use `pygame-ce` for modern Python versions)
* **Assets:** Manually collected and integrated sprites.
